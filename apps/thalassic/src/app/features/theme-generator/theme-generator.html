Sass

Load the theme with these palettes and role tones in place of its own: use this as the theme import in your global stylesheet. Every color role, light and dark, is built from them at compile time.

CSS

Override the color roles of the stock theme: load this file after the theme. Needs no Sass, and can be swapped in at runtime.

Palette partials

Replace the theme's default palettes: each file replaces its namesake in libs/themes/src/themes/thalassic/palettes/. Palettes only — role tones stay at the theme's defaults in _roles.scss; the Sass and CSS exports carry them.
